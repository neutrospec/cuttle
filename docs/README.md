# Documentation

The product is `cuttle`: the public repository `neutrospec/cuttle`, the Go
module `github.com/neutrospec/cuttle`, the Homebrew formula, binary, launchd
service, and XDG directories use that name. `squid` was the working name;
homebrew/core already ships a `squid` formula.

1. [Agent operating rules](../AGENTS.md) define the work loop, checkout rules,
   gates, and role ownership.
2. [Lessons](LESSONS.md) records repeated failures and their remedies.
3. [Glossary](GLOSSARY.md) defines the project terms and maps earlier
   wording to them.
4. [Roadmap](ROADMAP.md) states what each milestone must demonstrate.
5. [Design records](design/README.md) explain architecture and contracts.
   Start with [0002](design/0002-proxy-core-and-routing.md).
6. [Research notes](research/README.md) record protocol and client evidence.
7. [Compatibility matrix](COMPATIBILITY.md) tracks outcomes on actual clients.
8. [Tasks](TASKS.md) holds the current status and next action of each change.
9. [Open issues](OPEN_ISSUES.md) tracks significant carry-over work.
10. [Changelog](../CHANGELOG.md) lists the changes and upgrade steps of each
    release.
